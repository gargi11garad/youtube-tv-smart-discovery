# YouTube TV Discovery

A Streamlit concept for remote-friendly Smart TV discovery and navigation.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Prototype features

- Large, high contrast navigation and remote-friendly controls
- Personalized home rows, search, genre filters, and show details
- Watch list management and cross-device discovery concept
- Household interests, text size, focus contrast, and reduced-motion settings

All titles and descriptions are sample content. Saved items last only for the current app session.
